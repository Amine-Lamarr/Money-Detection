This is an <strong>Object Detection</strong> project I built using the <strong>YOLO algorithm</strong> and my own dataset. It detects <strong>Moroccan currency</strong> in an image and automatically counts the total amount of money. 💰 I developed a full web application for it, the model was trained with <strong>Python</strong>, while the website was built using <strong>HTML</strong>, <strong>CSS</strong>, and <strong>JavaScript</strong>. The backend is powered by <strong>FastAPI</strong> for smooth communication between the interface and the detection model.
